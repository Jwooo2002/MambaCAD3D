# 후보 실험의 성능 하락 진단

2026-11-10 13:38 KST 기준. 현재 기준 R0와 R1–R5의 4-fold, R6의 완료된 3-fold를 확인했다. 마지막 R6 fold 4 학습은 유지했다. 새 학습이나 설정 변경 없이 저장된 27개 모델·학습 기록·전체 환자별 patch 점수만 분석했다.

## 판단

후보들이 같은 이유로 실패한 것은 아니다. **R5의 한 fold는 실제 memory collapse**, R2는 복원 성능 저하와 과도한 집중, R3은 기존 memory 조회와 매우 다른 가중치 분포 및 환자 점수 집계 민감성이 확인됐다. R4는 환자 가중치와 epoch별 고유 patch 노출량을 동시에 바꾼 실험이다. 이것은 관찰과 작동 방식 진단이며, 각 요소가 AUROC 차이를 얼마나 일으켰는지 분리한 인과 추정은 아니다.

| 조건 | 평균 정상 validation MSE | 평균 max AUROC | 확인된 특징 |
| --- | ---: | ---: | --- |
| R0 기준 | 0.002070 | 0.7300 | memory 유효 슬롯 약 1.89개 |
| R1 dt | 0.002685 | 0.7075 | 복원 오차 증가. 일부 fold에서 dt 변화가 학습 후 거의 사라짐 |
| R2 λ | 0.004024 | 0.6675 | 복원 오차 약 1.94배, 유효 슬롯 약 1.28개 |
| R3 cosine | 0.002049 | 0.7075 | 복원 오차는 비슷하나 조회가 유효 약 288개 슬롯에 분산 |
| R4 sampling | 0.002472 | 0.6900 | 중복 추출로 한 epoch의 기대 고유 patch 비율 약 62–63% |
| R5 dt+λ | 0.014618 | 0.5900 | fold 3에서 거의 입력과 무관한 상수 복원 |

MSE는 마지막 epoch의 정상 validation 기록을 fold별 산술평균했다. 이 legacy 실행은 normal test와 validation을 공유하므로 독립 validation 성능을 뜻하지 않는다. 유효 슬롯 수는 고정 진단 patch의 각 위치에서 exp(attention entropy)를 계산한 평균이며, 전체 데이터에서 사용한 서로 다른 슬롯의 개수와 다르다.

## 1. Cosine: 정규화만 치환했지만 softmax 스케일까지 바뀜

- R0의 최대 attention 평균은 78.16%, R3은 0.631%였다. 유효 슬롯은 R0 1.89개에서 R3 287.51개로 증가했다(총 300개).
- τ=1 cosine logit은 −1~1에 제한된다. 따라서 300개 슬롯에서 한 슬롯의 최대 가능한 확률조차 exp(2)/(299+exp(2))=2.412%다. 현재 설정으로는 원래 모델 수준의 집중 자체가 불가능하다.
- 따라서 이 실험은 거리 함수와 조회 집중도를 함께 바꿨다. τ=1을 선택했던 제안은 이 스케일 차이를 충분히 통제하지 못했다. cosine 전체의 유효성을 기각하는 근거로 쓰기 어렵다.
- 다만 거의 균등한 attention이 곧 상수 출력이라는 뜻은 아니다. R3은 입력이 달라지면 복원 결과가 달라졌고, memory 출력을 고정 평균으로 교체하면 실제 출력과 큰 차이가 났다. R3을 collapse라고 부르지 않는다.
- fold 1의 정상 환자 max 점수 중앙값은 0.004264→0.003084, 질환 환자는 0.005245→0.003420이었다. 질환 점수가 더 크게 낮아지며 분리가 약해졌다. AUROC는 0.84→0.69였다. 병변 주석을 사용하지 않았으므로 이를 병변 자체를 더 잘 복원한 증거로 단정하지 않는다.

## 2. λ와 dt+λ: 현재 구현에서는 규제가 더 강해진 실험

- R2는 entropy 축을 수정한 실험이 아니다. 기존 entropy를 그대로 둔 채 λ를 0.0002→0.0006826667로 3.4133배 높였다. 수정 축에서의 크기 보정이라는 원래 제안과 다르며, 실행 전에 이 차이를 기록했더라도 지금 결과 해석에서 다시 구분해야 한다.
- R2의 정상 validation MSE는 R0의 약 1.94배이고 memory 최대 attention은 평균 92.80%다. 규제 증가와 더 좁은 memory 조합, 복원 저하가 함께 나타났다. 이것만으로 모든 fold의 성능 하락을 λ 하나에 인과적으로 귀속하지 않는다.
- R5 fold 3은 AUROC 0.47, 마지막 정상 validation MSE 0.045629(R0 같은 fold 0.001690, 약 27배)였다.
- 해당 모델의 진단 patch 137개에서 최대 attention 평균은 **99.999714%**, 모든 위치의 argmax는 같은 슬롯, 유효 슬롯은 1.000056개였다. 복원 영상의 입력 간 분산/입력 분산은 4.12e−10이었다. memory 출력을 고정 벡터로 치환해도 출력 변화/복원 오차는 4.12e−9에 불과했다. 이 fold는 거의 입력과 무관한 복원을 내는 collapse가 확인됐다.
- 다른 R2/R5 fold도 집중되지만 상수 복원은 아니었다. argmax가 한 슬롯에 몰린다는 사실만으로 collapse라고 판단하면 안 된다.
- 마지막 checkpoint의 첫 정상 학습 patch에서 손실별 gradient도 측정했다. entropy 손실의 숫자가 크다는 이유만으로 gradient가 복원 손실을 지배한다고 주장하지 않는다. 이 한 patch의 최종 gradient로 학습 초기 전체 경로를 설명할 수도 없다.

## 3. Sampling: 환자 균등화와 중복 추출 효과가 섞임

R4는 정상 환자와 해당 환자의 patch를 균등 추출하되 replacement=True이고, epoch당 총 추출 횟수는 원래 patch 수와 같다. 원래 shuffle은 모든 patch를 한 번씩 보지만 R4에서 한 epoch에 보는 고유 patch 수의 기댓값은 다음과 같다.

| Fold | 학습 patch 수 | 환자별 patch 수 범위 | 기대 고유 patch 비율/epoch |
| --- | ---: | ---: | ---: |
| 1 | 956 | 31–81 | 62.40% |
| 2 | 950 | 31–87 | 62.24% |
| 3 | 956 | 31–87 | 62.16% |
| 4 | 993 | 42–87 | 62.69% |

환자가 P명, 환자 i의 patch가 n_i개, 총 추출 N회이면 기대 고유 patch 수는 Σ n_i·[1−(1−1/(P·n_i))^N]이다. 실제 특정 epoch에서 관측한 비율이 아니며, 학습 전체에서 38%가 영구 누락된다는 뜻도 아니다. Test는 모든 patch를 그대로 평가했다. 이번 하락을 test에서 sampling하지 않은 탓이나 질환 patch가 test에서 빠진 탓으로 설명할 근거는 없다.

환자별 학습 비중만 분리해서 보려면, 전체 patch를 매 epoch 유지하면서 환자별 loss 가중치를 바꾸는 대조가 더 직접적이다. 이것은 후속 제안이고 새 학습은 실행하지 않았다.

## 4. dt 초기화와 공통 구현의 한계

- R1의 평균 정상 validation MSE는 약 1.30배로 증가했다. 기존 SSM의 방향별 파라미터 분리 문제를 유지한 상태에서 dt 초기화만 바꿨으므로, 올바른 방향별 SSM에서의 초기화 효과와 같다고 볼 수 없다.
- groups=2의 x_proj 출력은 방향마다 [dt, B, C] 순서인데, legacy는 전체 채널을 [2·rank, 2·state, 2·state]로 먼저 나눈다. 따라서 각 방향 파라미터가 올바르게 대응하지 않는다.
- 학습 후 진단 patch에서 R0의 층별 delta 중앙값은 약 0.6931이었다. R1 fold 3도 모든 층에서 이 값에 가까웠고 fold 2도 대부분 가까웠다. 일부 fold에는 초기화 차이가 남았지만, 초기에 지정한 작은 delta 범위가 최종 모델에 그대로 유지되는 것은 아니다. 초기화만으로 학습 안정성이 개선됐다는 증거는 없다.
- best_model_state=model.state_dict().copy()는 tensor를 독립 복사하지 않는다. 이 실행의 best_epoch는 실제 고정된 최적 checkpoint를 뜻하지 않으며, 최종 epoch 가중치를 평가했다. R0와 후보에 공통이므로 후보 하락의 단독 원인으로 확정할 수 없다.
- 같은 초기 seed와 fold 순서를 사용했지만 fold마다 seed를 재설정하지 않았다. 학습 길이가 달라지면 후속 fold의 초기화도 달라질 수 있다. 특히 한 fold의 붕괴를 모든 seed에서 재현되는 구조적 결함으로 일반화하지 않는다.

## 5. max 집계의 영향도 별도로 존재

전체 저장 patch 점수에서 같은 환자들의 집계만 다시 계산했다.

| 집계 | R0 평균 AUROC | R3 cosine 평균 AUROC |
| --- | ---: | ---: |
| 사전 주 평가 max | 0.7300 | 0.7075 |
| 보조 mean | 0.7925 | 0.8000 |
| 보조 상위 5% 평균 | 0.7325 | 0.7225 |

cosine이 모든 집계에서 더 나쁜 것은 아니다. max에서 소수 높은 patch 점수의 영향이 중요한 것으로 보이지만, 그 patch가 해부학적 변이·전처리 문제·병변 중 무엇인지는 이 분석으로 확인하지 않았다. mean의 좋은 숫자를 보고 주 평가를 바꾸거나, 이를 새 최적 설정의 검증 성능으로 제시하지 않는다.

## 다음 판단

1. 남은 R6 fold 4는 예정대로 완료한다. 현재 R6는 fold 1/2/3 AUROC 0.63/0.71/0.67, AP 0.8849/0.9224/0.9106이며 4-fold 평균은 미확정이다.
2. 추가 조합 확대보다, 현재 λ 증가의 근거를 재검토하고 cosine의 온도/조회 집중도를 정상 학습·검증 자료에서 먼저 진단한다. 시험 AUROC로 온도를 고르지 않는다.
3. 후속 비교를 한다면 fold별 초기화와 실제 최적 checkpoint 보관을 맞춰야 한다. 공통 오류를 수정한 실험은 별도 기준군을 두며 현재 legacy R0와 섞지 않는다.
4. 환자 균등화는 고유 patch 노출과 분리하고, 집계 비교는 사전 주 평가와 보조 분석을 구분한다.
