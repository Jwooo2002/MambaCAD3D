# Memory를 실제로 사용하는가

2026-11-10. 사용자의 “원래 memory를 잘 쓰지 않는 경향이 있었다”는 기억을 확인하기 위해, 가중치 중복과 저장 모델의 기능적 의존성을 따로 검사했다.

**결론: 300개 슬롯의 대부분이 중복되어 실질 용량을 거의 활용하지 못하는 현상은 원래 논문 체크포인트와 현재 R0 모두에서 확인됐다. 현재 R0는 남은 소수 벡터의 입력별 혼합을 복원에 사용한다. 따라서 memory 모듈 전체가 불필요하다고 확정할 수는 없다.**

## 1. 원래 논문 모델에도 슬롯 중복이 존재

원래 결과에 연결된 `data_0_05_8_32_CTCA_64_20251023_231210`의 네 체크포인트에서, 동일 군 내 벡터와의 L2 거리 1e−6 이하인 거대 중복군이 각각 297/297/297/296개였다(총 300개). 현재 기준 R0는 네 fold 모두 296개였다. 단순히 attention이 적게 가는 수준을 넘어, 저장된 memory 벡터 자체가 거의 같아진 현상이다.

중복군은 각 모델의 memory 벡터 norm 중앙 순위에 있는 행을 중심으로 측정했다. 이 검사는 해당 거대 군을 찾는 것으로, 모든 가능한 소규모 중복군을 완전 분류한 결과는 아니다. 현재 R0의 중심화된 memory 분산 99%는 3/4/4/4개의 방향으로 설명됐다.

## 2. 중복을 합쳐도 기능이 보존되는가

R0의 296개 중복 벡터를 대표 벡터 하나로 합쳐 **총 5개 벡터**로 계산했다. 중복된 슬롯은 같은 key/value를 반복한 것이므로, 대표 슬롯의 logit에 log(296)을 더해 원래 softmax 분모와 총 가중치를 보존했다. 단순히 295개를 삭제하고 동일 가중치로 다시 softmax한 실험은 아니다.

네 fold의 모든 test patch에서 평가했을 때:

- AUROC/AP는 각 fold에서 모두 그대로였다. 평균 AUROC 0.7300, AP 0.917334.
- 정상 복원 MSE 비율은 기준 대비 0.99999950–1.00000040이었다.
- memory 출력의 최대 절대 차이는 8.33e−7이었다.

현재 300개 슬롯 대부분을 합쳐도 거의 같은 함수가 된다는 직접적인 근거다. 이 결과는 처음부터 5개 슬롯으로 재학습해도 같은 성능이 나온다는 뜻은 아니다.

## 3. 소수 memory 벡터의 입력별 조회까지 없애면

저장된 encoder/decoder는 고정하고 memory 동작만 추론 시 바꿨다. 모든 기존 test patch를 평가했다.

| R0의 추론 조건 | 평균 max AUROC | 평균 AP | 정상 복원 MSE / 원래 MSE, fold 범위 |
| --- | ---: | ---: | ---: |
| 원래 300개 memory | 0.7300 | 0.9173 | 1배 |
| 중복을 보존적으로 합친 5개 | 0.7300 | 0.9173 | 약 1배 |
| 입력별 조회를 정상 학습 patch의 평균 출력으로 고정 | 0.5850 | 0.8564 | 43–93배 |
| 모든 슬롯을 균등 평균 | 0.5850 | 0.8523 | 52–103배 |
| 조회 가중치는 그대로 두고 value 대응만 섞음 | 0.5725 | 0.8424 | 51–102배 |
| 가장 높은 슬롯 하나만 100% 사용 | 0.3500 | 0.7763 | 158–400배 |

고정 평균은 정상 학습 환자 15명 각각의 처음/중간/마지막 patch에서 추출한 memory 출력을 모든 위치에 걸쳐 평균했다. 시험 데이터로 평균을 맞추지 않았다. Value permutation은 seed 741로 고정했으며 시험 성능으로 선택하지 않았다. Key/value를 함께 같은 순서로 섞는 경우에는 원래 readout이 허용 오차 내 보존됨을 대조 확인했다.

가장 높은 슬롯의 attention이 78%라고 해서, 나머지 22%의 혼합이 없어도 되는 것은 아니다. Top-1만 쓰면 복원은 크게 나빠졌다. 기존 R0는 몇 개 벡터의 연속적인 혼합 비율을 통해 입력 정보를 전달하는 데 의존한다. 코드상 encoder에서 decoder로 memory를 우회하는 별도 skip 경로도 없다.

다만 추론 도중 기능을 파괴한 모델은 memory 없이 처음부터 학습한 AE와 다른 조건이다. 이 표의 차이를 “memory가 AE 대비 AUROC를 0.145 올렸다”는 모듈 효과로 보고해서는 안 된다. Memory의 필요성·질환 탐지 이득은 동일 데이터·초기화·예산의 no-memory AE 재학습 대조가 있어야 판정할 수 있다. 해당 새 학습은 실행하지 않았다.

## 4. Cosine과 실제 collapse 대조

Cosine R3에는 R0와 같은 거대 중복군이 보이지 않았고, 중심화 memory의 분산 99%를 설명하는 방향 수는 fold별 20/17/24/33개였다. 평균 attention이 거의 균등해 보여도 입력 의존성은 남아 있었다.

- R3 원래 평균 AUROC 0.7075 → 정상 학습 memory 평균으로 고정하면 0.3150.
- 이때 정상 복원 MSE는 59–90배로 증가했다.
- Value 대응만 섞으면 평균 AUROC 0.2850이었다.

따라서 이전 진단에서 **cosine attention이 평평하다는 관찰을 memory 무시로 해석하면 안 된다.** Cosine은 벡터 다양성을 늘렸지만 현재 주 평가 성능을 높이지는 못했다. 슬롯을 많이 쓰는 것 자체가 좋은 이상 탐지의 증거는 아니다.

반면 R5 dt+λ fold 3은 실제 입력 조건부 조회가 사라진 대조 사례다. 정상 학습 평균으로 고정하거나 top-1만 사용해도 AUROC/AP는 0.4700/0.7917로 그대로였고, 정상 MSE 변화도 약 0.00035% 이하였다. 이는 이전의 거의 상수 복원 진단과 일치한다. 잘못된 다른 상수 벡터로 교체하면 출력이 바뀔 수 있으므로, collapse도 “decoder가 memory 값 자체에 전혀 의존하지 않는다”는 뜻은 아니다.

## 판단과 다음 비교

- 사용자의 기억은 **memory 대부분의 중복·실질 용량 미활용**이라는 의미에서 확인됐다. 원래 논문 모델부터 존재했던 현상이다.
- R0에서 λ를 더 키운 것은 이미 소수 슬롯에 집중된 상태를 더 좁혔을 가능성이 있다. R5의 완전한 조회 붕괴와 구분해서 해석한다.
- 현재의 소수 벡터 혼합이 정상 패턴 기억으로서 충분한지, 단순한 압축·복원 통로로 주로 작동하는지는 이 실험만으로 판정하지 못한다. 벡터 수가 적다는 이유만으로 정상 prototype 역할이 없다고 단정하지 않는다.
- 모듈 필요성을 보려면 현재 baseline과 대응하는 no-memory AE 대조가 가장 직접적이다. Cosine 온도나 슬롯 수를 시험 성능에 맞춰 선택하는 근거로 이번 개입 결과를 쓰지 않는다.
