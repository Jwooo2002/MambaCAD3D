# 최종 모델과 외부 평가 — 후속 단계 준비

상태: **자료 확인·후속 설계만 완료, 새 학습·외부 추론은 미실행.** 현재 고정200 epoch의 nested holdout 큐와48시간 deadline을 변경하지 않는다. 이 후속안은 첫 ASOCA 후보 성능이 나오기 전에 작성했다. 실제 시작은 현재 묶음의 중간 판정과 남은 예산 확인 후 별도 실행 기록으로 남긴다.

## 목적

현재 outer CV는 fold마다 inner validation으로 후보를 고르는 절차를 평가한다. 하나의 최종 설정을 가진 모델을 얻는 일과 구분한다. 후속 단계에서는 ASOCA 안에서 설정을 고정해 정상20명 전체로 모델을 학습하고, 외부 ImageCAS-X에서3개 seed의 성능을 확인하는 것이 목표다. 외부 결과를 보고 설정·seed·checkpoint·집계를 다시 고르지 않는다.

## 설정과 모델 선택안

- 현재32개 inner run이 모두 끝난 뒤, 후보별4fold×2seed의 평균 max-AUROC로 최종 설정1개를 고른다. 평균 AP가 P0보다0.02 넘게 낮으면 제외한다. 동률은 AP, 그다음 P0→P1→P2→P3 순서다. **Outer test와 외부 점수는 이 선택에 사용하지 않는다.** 이0.02는 운영 기준이지 임상 비열등성 한계가 아니다.
- 선택 설정과 P0를 ASOCA 정상20명 전체로 다시 학습한다. Seeds42/123/2024, 고정200 epoch, 현재와 같은 모델·전처리·batch·학습률·scheduler. 각 seed에서 초기값과 전체 patch 순서를 두 조건에 일치시킨다. 최대6회이며 P0가 선택되면 중복하지 않는다.
- 세 seed 중 높은 것만 고르지 않고 모두 보고한다. 배포용 단일 checkpoint가 필요하면 사전에 정한 seed42를 대표로 두고 나머지는 재현성 평가에 사용한다. 외부 AUROC로 대표 seed를 고르지 않는다. 이 문서 작성 시점에는 어떤 후보도 선택하지 않았다.

## 외부 평가안

선택된 설정과 P0의 최종 모델마다 동일한800명 전체patch를 평가한다. 주 집계는 max, 주지표AUROC, AP 보조. 다른 집계는 고정된 보조 분석이다. 환자별·patch별 원점수와 모델/file hash를 보존하고 정상/질환 전체에서 patch 누락·중복·label·지표를 독립 검산한다.

정상412명·질환388명으로 AP의 질환비율 기준은0.485다. 세 seed 각각의 AUROC/AP와 paired 차이, 세 seed 평균 차이를 보고한다. Class별 환자 bootstrap에서는 같은 환자의 추출을 모든 seed와 두 조건에 공유한다. CI는 고정된 모델과 선택에 조건부이고 모든 재학습 불확실성을 포함하지 않는다. 모델3개를 독립 환자 수로 취급하지 않는다.

이 안은 전체 정상20명을 학습에 사용하므로 새로운 독립 threshold calibration 자료가 없다. 따라서 새 민감도·특이도 threshold를 외부 label이나 학습 점수에 맞춰 만들지 않는다. 첫 목적은 threshold가 필요 없는 AUROC/AP와 재현성이다. 임상 운영점 검증은 적절한 별도 calibration 설계를 요구한다.

ASOCA와 ImageCAS-X는 모두 과거 수정본 평가에 노출된 이력이 있다. 지금 새로 설정을 고정해 평가하더라도 과거 미사용 코호트라고 주장하지 않는다. 현재 후보에 대한 외부 결과는 이 문서 작성 시점까지 확인하지 않았다. 참조 중심선 기반 환자 수준 평가이며 병변 위치의 정답 검증을 대신하지 않는다.
